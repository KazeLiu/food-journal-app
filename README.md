## 确定的方向

- Flutter / Dart，Android 优先；SQLite 本地保存，无账号、自有服务器或云同步。
- 三个底部入口：AI 教练、我的记录、我的。长期聊天、连续发送、前台串行处理。
- 文字、拍照、相册；单条最多 3 图；有效识别结果保存后删除 APP 临时副本，不删除相册原图。
- 仅 **Responses API**，一组 Base URL / Key；模型列表或手输 ID，文字与图片各设主、兜底模型。
- 自然语言流式回复；实际保存成功后显示记录卡片，由客户端决定成功状态。
- 一餐分组、内部多个食物；估算热量、蛋白质、脂肪、碳水；首页简洁，详情信息完整。
- 区分用户数值、包装标签、个人食品资料和 AI 估算；食品资料和长期偏好经同意才保存。
- 搜索、历史查询、聊天纠正、逐项撤销、日历联动、独立的多次体重记录。
- AI 失败可手动记，营养可空；后续正常 AI 成功后补缺失值，不覆盖已有数值。
- CSV、完整备份恢复、可选备份密码；Key 和原图不进入备份。
- 不做语音、扫码、热量目标、剩余额度、体重趋势 / 预测、固定虚拟角色和打卡奖励。
