# AI 减脂伙伴 · Android 工程

私人饮食、运动与体重记录工具，Flutter / Dart + SQLite，无账号或自有服务端。完整范围见根目录 docs/01，当前实现与构建证据见 docs/10。

## 使用

1. 安装 debug APK 后选择体重默认单位。可跳过引导，直接手动新增饮食或体重。
2. 使用 AI 时进入“我的 → AI 接口与模型”，填写接口前缀、Key 和文字主模型即可聊天。需要识图时再填图片主模型，两个兜底都可留空；填写时同类型主备不能同 ID。每个模型可单独选择思考强度，默认跟随服务端；只支持 Responses。
3. 在 AI伙伴发送文字或最多 3 张图片。图片先识别成摘要，再交文字模型；发送后有小图，点击可放大。保存后显示记录卡片，同时保留 AI 原回复。我的记录中可查看月历、编辑、删除和撤销。

今日概览和三个快捷入口固定在 AI伙伴页顶部，下方聊天独立滚动；上翻历史时仍能查看当天统计和使用快捷入口。标题栏只保留搜索；快捷按钮等宽居中，每个最长 180dp。聊天和食品表单的图片请求先显示实际请求字节的本机发送百分比，再显示“等待识别结果”和两分钟逐渐放慢的预估进度；超过两分钟提示耐心等待。上传完成不代表服务端已收齐，后半段也不代表模型实际完成比例。

底部导航仅显示图标，保留无障碍名称；顶部与输入区增加留白。图片大图预览点击图片或空白处都可返回，拖动和双指缩放仍可使用。

今天未说明时间的 AI 记录默认取发送时刻；补记“昨天上午 / 前天下午”会保留时段，不补具体时刻。手动新增饮食和体重默认当前时间，可自行调整或清空；编辑既有记录保留原时间。

从日历进入聊天后，未明确其他日期的问题针对所选日；发出后的消息保留日期 / 记录标记，可点回原日期或记录。引用原话显示原日期，未另选日期时沿用该引用的日期。

所有模型首次失败后都在原模型重试一次；主模型两次失败才切换已配置的兜底，兜底也最多两次。任一次成功即停止该阶段尝试，主动停止不再重试；聊天、识图、查询后总结、补算、食品拍照和能力检查沿用此规则。

聊天动作协议字段错误会指出具体项与字段，并在剩余的有界尝试中反馈给模型纠正，不额外增加请求次数，不猜测缺失的修改动作。

食品资料自动匹配名称、别名和品牌，精确名称 / 别名优先；只有品牌相同不直接套用营养。拍照填表和聊天的资料建议都允许 AI 联想常用别名，例如“零度可乐、零度、无糖可乐”；表单中可核对修改，保存后才用于匹配，泛称存在歧义时仍需确认产品。纠正产品名或要求重算时先核对资料库，客户端读取库中原值按食用量换算。已保存的标签资料仍标为资料库来源；后续补充包装规格、要求保存刚拍过的标签时可继续使用已保存的识图摘要，无需重拍。

接口返回的 think 会独立保留：思考时展开并流式显示，正文开始后自动折叠，点击可再展开；使用灰色、13px 斜体，不放入后续模型上下文或引用快照。若服务要求显式请求，可在 AI 设置开启“请求思考摘要”；该开关默认关闭，不改变旧接口参数。完整备份包含思考内容，删除聊天时一并删除。

聊天明细与 think 使用同样的紧凑标题和小箭头，没有边框或上下分割线，整行保留48dp点击区域。展开后直接显示内容，think 正文也能点击收起；手动折叠时暂停底部跟随并尽量保留当前阅读位置。小字仅显示保存状态，旧回执中重复的正文不再显示；最终协议失败时保留已收到的自然回复并标明未保存。

“我的 → 食品资料库 → 添加食品资料”右上角点击“AI 拍照识别”，先拍同一食品的照片，可继续补拍，最多3张；点击“开始识别”后综合填写名称、别名、品牌、规格、营养基准、四项营养和备注。识别模态框先显示本机发送进度，再显示识别预估，不能点遮罩或返回退出，可明确停止识别。完成后仍在添加页，Tips提示核对并点击“保存资料”，不会发送聊天或记录已吃 / 已喝；配料、过敏原等看清后写入可编辑备注，未知值留空，kJ由客户端换算。

相机导致进程重建时恢复食品表单和照片，不恢复为聊天草稿，也不自动调用模型。表单照片只在私有草稿中暂存，保存资料或确认放弃时清理，不放入备份。

Key 保存在设备安全存储；业务备份不包含 Key、AI 配置或图片预览。压缩预览随聊天保留，删除聊天或清空数据时清理；导入完整备份也会替换聊天并清除旧预览，替换前保留一份不含图片的应用内部安全副本。旧版已清理的图片无法恢复。

运动可与饮食混合描述，先保存再可选补充；“我的记录 → 日期旁 + → 记录运动”可离线新增。详情支持 AI / 直接编辑、删除和逐项撤销。消耗与饮食分别汇总，未知不写 0；数据管理提供单独运动 CSV，完整备份含运动与历史关系，支持 schema 1–3 旧文件恢复到 schema 4。

## 构建

已使用 Flutter 3.19.4 / Dart 3.3.2、JDK 17.0.9、Android SDK 34、NDK 25.1.8937393、Gradle 8.2、AGP 8.2.2、Kotlin 1.9.22。依赖以 pubspec.lock 为准；最低 Android 7.0（API 24），compile / target SDK 34。

在本目录执行：

```powershell
flutter pub get
flutter analyze --no-pub
flutter build apk --debug --no-pub
```

本机 Flutter 路径为 D:\FlutterSDK，JDK 为 D:\Java\hold-that-bite-jdk17，Android SDK 为 D:\AndroidSDK。其他环境应配置自己的 Flutter / Java / Android SDK 路径，不复制 local.properties。

产物：build/app/outputs/flutter-apk/app-debug.apk。应用 ID 为 local.foodjournal.app，版本 0.1.18+19。debug 包供个人设备验收；正式发布需要配置独立发布签名，不使用调试签名冒充正式包。

## 源码入口

- main.dart / app.dart：服务初始化、三页、引导和主题。
- core：schema、时间 / 数值约定、图片生命周期和共用组件。
- records：本地读取与汇总、事务账本 / 快照 / 版本 / 撤销、手动表单和记录卡。
- chat：Responses / SSE、FIFO、主备、上下文与校验、追问 / 确认、空值补算和消息搜索。
- calendar：真实月历、每日明细、全部体重与历史。
- library / settings：食品资料、授权记忆、接口和外观设置。
- data_management：CSV、加密备份、校验预览、整库替换、安全副本与清除。
