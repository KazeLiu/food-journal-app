# 食记 · Android 工程

私人饮食、运动与体重记录工具，Flutter / Dart + SQLite，无账号或自有服务端。完整范围见根目录 docs/01，当前实现与构建证据见 docs/10。

## 使用

1. 安装 APK 后选择体重默认单位。可跳过引导，直接手动新增饮食、运动或体重。此前 debug 包与独立签名 release 不可互相覆盖，换装先按[发行说明](../docs/releases/v0.1.22.md)完整备份。
2. 使用 AI 时进入“我的 → AI 接口与模型”，填写接口前缀、Key 和文字主模型即可聊天。需要识图时再填图片主模型，两个兜底都可留空；填写时同类型主备不能同 ID。每个模型可单独选择思考强度，默认跟随服务端；只支持 Responses。
3. 在 AI伙伴发送文字或最多 3 张图片。图片先识别成摘要，再交文字模型；发送后有小图，点击可放大。保存后显示记录卡片，同时保留 AI 原回复。我的记录中可查看月历、编辑、删除和撤销。

支持应用快捷方式的桌面可长按“食记”图标：

- **记录体重**：打开今天的原有体重表单，单位沿用设置；填写后手动保存。
- **快速拍照录入**：先恢复已有聊天草稿，再打开相机；拍照后图片留在草稿，输入框获得焦点，等待补充和发送。不自动调用 AI 或创建记录，取消不丢草稿，最多3张图片。

快捷入口不绕过首次引导或未保存表单的退出确认；已有食品资料表单草稿保留，普通启动仍可恢复。应用展示名改为食记，applicationId、数据目录、签名及现有主图标不变。

今日概览与右侧等高的“今日分析”并排固定在 AI伙伴页顶部，概览占大部分宽度；下方聊天独立滚动。不再显示置顶“记录饮食 / 记录体重”，聊天和记录页新增入口保留。标题栏只保留搜索。聊天和食品表单的图片请求先显示实际请求字节的本机发送百分比，再显示“等待识别结果”和两分钟逐渐放慢的预估进度；超过两分钟提示耐心等待。上传完成不代表服务端已收齐，后半段也不代表模型实际完成比例。

底部导航仅显示图标，保留无障碍名称；顶部与输入区增加留白。图片大图预览点击图片或空白处都可返回，拖动和双指缩放仍可使用。

今天未说明时间的 AI 记录默认取发送时刻；补记“昨天上午 / 前天下午”会保留时段，不补具体时刻。手动新增饮食和体重默认当前时间，可自行调整或清空；编辑既有记录保留原时间。

从日历进入聊天后，未明确其他日期的问题针对所选日；发出后的消息保留日期 / 记录标记，可点回原日期或记录。引用原话显示原日期，未另选日期时沿用该引用的日期。

所有模型首次失败后都在原模型重试一次；主模型两次失败才切换已配置的兜底，兜底也最多两次。任一次成功即停止该阶段尝试，主动停止不再重试；聊天、识图、查询后总结、补算、食品拍照和能力检查沿用此规则。

聊天动作协议字段错误会指出具体项与字段，并在剩余的有界尝试中反馈给模型纠正，不额外增加请求次数，不猜测缺失的修改动作。

食品资料通过精简目录让现有文字模型结合含义、类别、别名、做法、形态和相关对话寻找候选，再按真实 ID 取回所需营养详情；不增加“常吃款”，不按手动或 AI 建议入库决定优先级。明确同款由客户端按库原值和实际食用量换算，保留 ID / 版本 / 快照；只是同类参考则标 AI，注明条目与份量假设、保留用户原称呼。候选不唯一时优先合理估算，不反复选商品；不平均不同类别、不按相近字面强套，例如金华火腿不能因此套用火腿肠。拍照填表与聊天建议仍可联想别名，保存资料需用户确认；后续保存已拍标签或补规格仍可使用对应识图摘要。纠正只更新原记录，不重算其他历史。

接口返回的 think 会独立保留：思考时展开并流式显示，正文开始后自动折叠，点击可再展开；使用灰色、13px 斜体，不放入后续模型上下文或引用快照。若服务要求显式请求，可在 AI 设置开启“请求思考摘要”；该开关默认关闭，不改变旧接口参数。完整备份包含思考内容，删除聊天时一并删除。

聊天明细与 think 使用同样的紧凑标题和小箭头，没有边框或上下分割线，整行保留48dp点击区域。展开后直接显示内容，think 正文也能点击收起；手动折叠时暂停底部跟随并尽量保留当前阅读位置。小字仅显示保存状态，旧回执中重复的正文不再显示；最终协议失败时保留已收到的自然回复并标明未保存。

“我的 → 食品资料库 → 添加食品资料”右上角点击“AI 拍照识别”，先拍同一食品的照片，可继续补拍，最多3张；点击“开始识别”后综合填写名称、别名、品牌、规格、营养基准、四项营养和备注。识别模态框先显示本机发送进度，再显示识别预估，不能点遮罩或返回退出，可明确停止识别。完成后仍在添加页，Tips提示核对并点击“保存资料”，不会发送聊天或记录已吃 / 已喝；配料、过敏原等看清后写入可编辑备注，未知值留空，kJ由客户端换算。

相机导致进程重建时恢复食品表单和照片，不恢复为聊天草稿，也不自动调用模型。表单照片只在私有草稿中暂存，保存资料或确认放弃时清理，不放入备份。

Key 保存在设备安全存储；业务备份不包含 Key、AI 配置或图片预览。压缩预览随聊天保留，删除聊天或清空数据时清理；导入完整备份也会替换聊天并清除旧预览，替换前保留一份不含图片的应用内部安全副本。旧版已清理的图片无法恢复。

运动可与饮食混合描述，先保存再可选补充；有运动类型和时长时 AI 主动按合理范围取中值，不要求准确消耗、泳姿、强度或体重。假设和范围保留，用户数值优先；未说时长仍可先保存。“我的记录 → 日期旁 + → 记录运动”可离线新增，详情支持 AI / 直接编辑、删除和逐项撤销。消耗与饮食分别汇总；运动 CSV、完整备份和历史关系共用 schema 4，保留旧 MET 依据并支持 schema 1–3 旧文件恢复。

外观采用石墨黑与柔和珊瑚橘，直接替换旧配色。跟随系统 / 浅色 / 深色沿用原有设置；公共组件、聊天、饮食 / 运动 / 体重记录和日历统一取色。App 图标资源不变。

“我的 → 估算参考”可选设置身高（cm）与性别，未设置不阻塞记录或估算。资料保存在 app_settings，随文字对话提供给 AI 作为运动消耗参考，不改变食物营养、不会自动重算旧运动；可清空并随完整备份 / 内部安全副本保留。

## 构建

已使用 Flutter 3.19.4 / Dart 3.3.2、JDK 17.0.9、Android SDK 34、NDK 25.1.8937393、Gradle 8.2、AGP 8.2.2、Kotlin 1.9.22。依赖以 pubspec.lock 为准；最低 Android 7.0（API 24），compile / target SDK 34。

在本目录执行：

```powershell
flutter pub get
flutter analyze --no-pub
flutter build apk --debug --no-pub
```

本机 Flutter 路径为 D:\FlutterSDK，JDK 为 D:\Java\hold-that-bite-jdk17，Android SDK 为 D:\AndroidSDK。其他环境应配置自己的 Flutter / Java / Android SDK 路径，不复制 local.properties。

debug 产物为 build/app/outputs/flutter-apk/app-debug.apk，版本化命名 food-journal-<版本>-debug.apk。应用 ID 为 local.foodjournal.app，源码版本 0.1.23+24，展示名称为食记；debug 沿用原调试签名，不能跨签名覆盖 release。0.1.23 仅构建 release，不构建 debug 或安装设备；既往设备证据见 docs/10。

### release 与发布签名

release 使用独立签名，不回退到 debug 签名。将 `android/key.properties.example` 按字段配置为不入库的 `android/key.properties`，或通过 `FOOD_JOURNAL_SIGNING_PROPERTIES` 指向外部私有配置。配置由 Gradle 读取，不将密码写入命令行、源码或发布说明。

本机已获准创建的签名保存在 `%USERPROFILE%\.android\food-journal-app\`，目录含 `release.jks` 和 `key.properties`，仅当前用户及 SYSTEM 可访问。应私下备份整个目录；密钥或密码丢失后无法继续同签名升级。签名文件、密码与 AI 配置都不作为发行附件。

```powershell
$env:FOOD_JOURNAL_SIGNING_PROPERTIES = Join-Path $env:USERPROFILE '.android\food-journal-app\key.properties'
flutter build apk --release --no-pub
```

release 产物为 build/app/outputs/flutter-apk/app-release.apk，版本化命名为 food-journal-<版本>-release.apk。当前 [0.1.23 正式版](https://github.com/KazeLiu/food-journal-app/releases/tag/v0.1.23) 提供 food-journal-0.1.23-release.apk，沿用既有发布签名，可覆盖同发布签名的 0.1.20 / 0.1.22 release 包。本轮修复与验证范围见[发行说明](../docs/releases/v0.1.23.md)；首次从 debug 换装的备份、图片与 AI 配置限制见[换装说明](../docs/releases/v0.1.22.md#从-debug-包换装前先备份)。

## 源码入口

- main.dart / app.dart：服务初始化、三页、引导和主题。
- core：schema、时间 / 数值约定、图片生命周期和共用组件。
- records：本地读取与汇总、事务账本 / 快照 / 版本 / 撤销、手动表单和记录卡。
- chat：Responses / SSE、FIFO、主备、上下文与校验、追问 / 确认、空值补算和消息搜索。
- calendar：真实月历、每日明细、全部体重与历史。
- library / settings：食品资料、授权记忆、接口和外观设置。
- data_management：CSV、加密备份、校验预览、整库替换、安全副本与清除。

0.1.18 已通过输入框调用现有 DeepSeek 核对混合保存、原记录补充、消耗估算 / 纠正、查询和删除撤销；0.1.19 已查看新主题的浅深色、系统跟随、重启保留、大字体与相关页面。0.1.20 已安装并实际确认：无泳姿 / 强度 / 适用体重的 15 分钟游泳可按范围取中值保存，详情展示依据。实际范围见 docs/10；320dp 窄屏、软键盘、系统选择器和完整恢复仍按 docs/06 由用户验收。
