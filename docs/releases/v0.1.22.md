# 食记 0.1.22

Android 正式版，应用版本 **0.1.22（23）**，最低 Android 7.0。通用 release APK 约 53 MiB，包含 arm64-v8a、armeabi-v7a 和 x86_64，沿用 0.1.20 预发行版的独立发布签名。

## 本次更新

- 项目与软件名称统一为“食记”，保留原图标、包名和已有数据。
- 长按桌面图标新增“记录体重”和“快速拍照录入”。拍照后回到聊天草稿并聚焦输入框，等待补充文字和手动发送，不自动调用 AI 或保存饮食。
- 首页移除置顶的两项记录按钮，今日概览与等高的“今日分析”并排，留出更多聊天空间。
- 设置可选填写身高和性别，供运动粗估参考；不改变食物营养，也不自动重算历史运动，完整备份保留资料。
- 食品资料结合含义、类别、别名、做法、形态和相关对话寻找候选。明确同款按库原值换算并保留快照；相近食品仅作 AI 估算参考，保留用户原称呼，不反复要求选择商品。
- 拉开详情“估算与来源依据”中说明文字与逐项依据的间距，更新 README，感谢 [LINUX DO 社区](https://linux.do/)。

## 升级安装

已安装同发布签名的 0.1.20 release 包，可直接覆盖升级；应用名称变化不会新建数据目录。升级前建议保留一份完整备份。

### 从 debug 包换装前先备份

**debug 与 release 签名不同，不能直接覆盖。不要先卸载旧包。**

1. 在旧包“我的 → 导出、备份与恢复”导出完整备份，保存到应用目录以外的位置；保管好备份密码。
2. 打开恢复预览，确认日期和记录数量后取消，不执行替换。保留旧 APK 与备份，再卸载 debug 包、安装本 release APK 并恢复。
3. 备份不包含 API Key、AI 接口配置和聊天图片预览；换装后重新配置 AI，旧预览不能通过备份恢复。

## 已确认与待确认

debug / release 构建成功，发布签名校验及版本、架构、非 debuggable 元数据已核对。MuMu 已确认新名称、长按菜单、体重入口和未保存表单保护；首页与身高 / 性别已有此前界面和真实 AI 咨询记录。

MuMu 相机未返回有效照片，拍照回填、输入框聚焦及相机进程重建由用户在手机确认。新资料匹配尚未作真实 AI 判断核对；窄屏 / 软键盘、完整恢复替换和其他模型组合仍需实际验收。本轮未新增、修改或运行自动化测试；完整按日上下文（D09）尚未开发。
