# 食记 0.1.23

Android 正式版，应用版本 **0.1.23（24）**，最低 Android 7.0。通用 release APK 约 53 MiB，包含 arm64-v8a、armeabi-v7a 和 x86_64，沿用既有发布签名和数据库 schema 4。

## 本次修复

- 修复食品资料的包装规格为空或字符串时，生成 AI 聊天上下文失败的问题。
- 修复跨日期统计餐数时，不同日期的同一餐别被合并少算的问题；同一天同一餐别仍去重，加餐次数独立统计。
- 修复设备时区变化后，编辑记录其他内容时意外改写原时间戳的问题；日期和时间不变时保留原时间戳与时区偏移。
- 修复恢复选图失败或图片超限时阻断应用启动的问题；保留已有草稿，最多恢复至 3 张图片，并明确提示未加入的照片或选择器错误。

## 升级安装

已安装同发布签名的 0.1.20 / 0.1.22 release 包，可直接覆盖升级，建议先保留完整备份。debug 包与 release 签名不同，不能直接覆盖；请先按[换装说明](https://github.com/KazeLiu/food-journal-app/blob/main/docs/releases/v0.1.22.md#从-debug-包换装前先备份)备份，不要先卸载旧包。

## 验证范围

release 构建成功，已核对版本、包名、架构及非 debuggable 元数据，APK 签名校验通过，签名证书与 0.1.22 相同。已核对修改代码与调用关系；本次不新增、修改或运行自动化测试，不安装或启动应用，上述场景的真机表现仍需确认。
