# AI 减脂伙伴 0.1.20 预发行版

Android release APK，应用版本 **0.1.20（21）**，最低 Android 7.0；通用包包含 arm64-v8a、armeabi-v7a 和 x86_64，约 53 MiB。使用独立发布签名，后续 release 版本沿用该签名。

## 本次内容

- 饮食与运动可在同一条 AI 对话中描述，分别保存、查看和纠正；支持运动补充、编辑、删除撤销、日历、独立汇总、CSV 与完整备份。
- 有运动类型和时长即可主动粗估合理消耗范围，取中值显示“约 N kcal”；不要求准确卡路里、泳姿、强度或体重，详情保留范围与假设，用户明确数值优先。
- 石墨黑 × 柔和珊瑚橘直接替换旧配色，支持浅色、深色和跟随系统，包含运动界面；保留已有 App 图标。

## 从 debug 包换装前先备份

**本 APK 的发布签名与此前 debug 包不同，不能直接覆盖安装。不要先卸载旧包。**

1. 在旧包“我的 → 导出、备份与恢复”导出完整备份，保存到应用目录以外的位置；记住自己设置的备份密码。
2. 用该文件打开恢复预览，确认日期和记录数量后取消，不执行替换。保留旧 APK 与备份文件，再卸载 debug 包、安装本 release APK 并恢复备份。
3. 完整备份不含 API Key、AI 接口配置和聊天图片预览；换装后需要重新配置 AI，旧预览不能通过备份恢复。

不想换装的现有 debug 用户可继续使用原包。后续相同发布签名、较高版本的 release APK 可以直接升级。

## 实际检查范围

已在 MuMu 16384 用 debug 构建和现有 DeepSeek 核对混合记录、同 ID 补充 / 修改、消耗估算、历史查询和删除撤销，以及新主题浅深色与系统跟随。release 构建成功，独立 APK v2 签名校验通过，版本 / 架构和非 debuggable 元数据已核对；不卸载现有模拟器应用来强装不同签名。

本次不新增、修改或运行自动化测试。手机窄屏 / 软键盘、系统文件选择器、完整恢复替换和其他模型组合仍需实际验收；D09 的完整按日上下文尚未开发。
