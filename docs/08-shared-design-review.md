## 1. 来源与采用方式

来源：[讨论减肥 APP 分享对话](https://chatgpt.com/share/6ad62c74-a444-83ea-9f21-6a84cade9c97)，核对日期2026-10-19。已读取公开文字对话，查看整体概念图、聊天原型和相关可见组件代码，并与开发文档对照。

用户已明确：末尾要求精简是因为反复提问，不代表删除此前逐项选定的设计。采用完整的已选设计；语音、热量目标、体重趋势 / 预测、扫码、固定角色等明确否定内容不恢复。互斥方案的演示不要求一起实现。

下表S编号按公开的用户 / 助手文字消息顺序计数，只是定位索引。正式产品、数据、接口和恢复契约分别以01、03、04、05为准；D01–D03 的已确认选择见09。

## 3. 原型与Flutter的对应

原可见代码是DIL / GenUI标记，不是Flutter工程。可复用的是颜色、布局层次、条件展开、操作分组和数据展示逻辑，再用Flutter组件表达。

| 原型部分 | 采用内容 | 不照搬内容 |
| --- | --- | --- |
| S028三页概念 | 留白、圆角、气泡、三入口 | 人物、五个底部标签、目标与趋势 |
| S044 / S056卡片 | 餐名、主数值、日期、修改 / 撤销 | 未真实提交就亮成功状态 |
| S074概览 | 一行餐数热量、详情入口，按用户要求固定顶部 | 固定演示统计；覆盖聊天内容而不预留独立区域 |
| S076 / S078明细 | 默认折叠、按食物展开营养 | 固定演示数组、强迫称重 |
| S080日详情 | 热量下面三格营养和分餐 | 全部当准确全天摄入 |
| S090月历 | 周一开头、双点、选中日、图例 | 固定年份、固定空格数和模拟记录 |
| S094长按 | 复制、纠正、删聊天 | 删除聊天顺带删除业务事实 |
| S100依据 | 折叠显示简短假设 | 事后临时生成的伪依据 |
| S104 / S106资料卡 | 保存确认、旧新并排、稍后不存 | 自动长期覆盖、历史重算 |
| S114添加图片 | 两个入口 | 语音或照片类型选择 |

可复用原始代码节选保存在 [shared-ui-components.md](../references/shared-ui-components.md)。它用于参考，不是运行入口；没有引入GenUI运行时或第二套UI框架。

## 4. 样式与细节

原参考浅色Token：背景#FFF8F2、强调#F29B83、紫#B7A4E8、绿#92C9B1、正文#35313D；卡片白色、气泡#FCE6DF、分隔#F1E2DE。

参考430px只是演示容器，不硬编码手机宽。小字号和浅色白字不照搬：正文16sp、辅助14sp、48dp点击区，深色文字配浅强调底。深色主题采用02的配套设计，不能简单反转照片或所有颜色。

原型按钮中的 GenUI.issueNewTurn 用于继续原ChatGPT讨论，不是产品业务接口，不移植。AsyncImage为示意图片，不为APP下载这些餐食照；用户自己发送的压缩预览按确认方案随聊天保留和删除。日期跨年、营养汇总、保存状态和菜单动作都需要真实本地实现，演示可点击不代表这些能力已经完成。
